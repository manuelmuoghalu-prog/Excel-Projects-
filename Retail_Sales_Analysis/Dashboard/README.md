# 📊 Dashboard

Contains the interactive Excel workbook for the Retail Sales Analysis project.

**File:** `retail_sales_analysis_final.xlsx`

## What's inside
- **Dashboard** sheet (the only visible one): KPI cards, four charts, slicers and a date timeline
- **Hidden sheets:** six PivotTables, the cleaned `SalesData` table and the original raw data

## How to open
1. Download the file and open it in **desktop Excel** (2016 or later).
2. Go to the **Dashboard** sheet and use the slicers and timeline to filter.
3. To see the data and pivots, right-click any sheet tab → **Unhide**.
4. After changing the data, use **Data → Refresh All**.

> Slicers and timelines work best in desktop Excel and may not display correctly in Google Sheets or LibreOffice.
